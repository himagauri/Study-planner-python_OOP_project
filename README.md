
# Smart Study Planner

>About the Project:
This is a simple study planner made using Python. 
It helps students plan their study schedule and keep track of the topics they need to complete.

I made this project using basic Python OOPS concepts.

>Features:
- Add new study tasks
- View all added tasks
- Mark tasks as completed
- Delete tasks
- Check study progress
- Save tasks so they are available even after closing the program

>Concepts Used:
- Classes and Objects
- Encapsulation
- Functions and Methods
- Lists
- Loops and Conditional Statements
- File Handling

>Tools Used:
- Python
- CSV module
- OS module

>How to Run:
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run 'study_planner.py'.

>Files:
- 'study_planner.py' – Contains the main Python program.
- 'study_tasks.csv' – Stores the study tasks.
- 'README.md' – Contains information about the project.

>Conclusion:
This project helped me understand how Python classes and objects work. It also gave me an idea of how Python can be used to create simple applications that are useful in everyday life.
